I build the parts of software that have to stay correct: access control, booking concurrency, payments and background jobs.

I’m a backend software engineer and 2026 Computer Science graduate from Hyderabad. I work mostly in Python, Django and PostgreSQL, and I like the unglamorous parts of a system: permissions, data integrity and the jobs that run in the background.

At Sria Infotech I built the Academics and Library modules of Eskoolia, a multi-tenant school ERP, and worked on access-control and architecture analysis for NXdesk, a Frappe-based ERP and Helpdesk platform that is still in development.

On my own I built Hostel Hunt: a Django REST backend, a Next.js owner dashboard and a Flutter student app, with booking locks, sandbox payments and CI. It is pre-launch and runs on staging.

Four habits, each tied to real code in a public repository.

01 / 04

Booking holds use transactional row locks (select_for_update and SKIP LOCKED) and expire on their own. Locking tests cover two students competing for the same bed.

02 / 04

Tenant isolation
